# Lesson NN: Title

**Status:** Draft. **Environment:** Specify host and shell. **Prerequisites:** Demonstrated skills.

## Practical purpose

Describe the task and what the learner will independently demonstrate.

## Recall and environment

Ask two short closed-notes questions. Confirm `hostname`, `whoami`, and `pwd` before execution.

## Explain

| Part | Meaning | Scope or effect |
|---|---|---|
| Command | What it does | What it reads or changes |
| Option | How behavior changes | Relevant limitation |
| Argument | Target or input | Boundary or destination |

## Predict, then execute

Use a small reproducible fixture. Explain file creation or overwrite before showing the command. Ask for a prediction first. Put answers in a collapsed section.

## Verify and troubleshoot

Compare actual and expected output. Explain ordinary failures and evidence limits. Resolve unexpected output before continuing.

## Independent application

Change a filename, pattern, dataset, or environment. Ask the learner to choose the command independently.

## Teach-back and completion

Ask for the concept, effect, evidence limits, and practical use. Record actual evidence and remaining gaps. Completion requires demonstrated understanding.

## Sources

Link official documentation and relevant local `man` or `help` entries. Identify distribution-specific behavior.
